# mostek-kultura — pravidla projektu

Komunikuj česky. Stručnost a přímost, minimum omáčky. Identifikátory v kódu a docstringy anglicky, prózu (README, komentáře k rozhodnutím, commity) česky.

## Co to je

Denní agregátor kulturních akcí v okolí obce Mostek. GitHub Actions (hlavní cron 04:30 UTC, záložní pokusy 05:17, 07:17 a 10:17 UTC) spustí `python -m mostek_kultura build`, výsledek (`site/`) jde na GitHub Pages: https://ivolarys.github.io/mostkultura/. Plánované pokusy kontrolují veřejné `status.json` a přeskočí se jen po publikovaném buildu od poslední hranice 04:30 UTC; při chybě kontroly se build spustí. Push a `workflow_dispatch` běží vždy. Home Assistant čte `summary.json` (REST senzory) a stránku zobrazuje v iframe (`?embed=1`). Plán: `~/.claude/plans/cht-l-bych-ud-lat-aplikaci-validated-quasar.md`.

## Delegování práce na subagenty (modely)

- **GPT-6 Astra (`gpt-6-astra`)**: hlavní model pro návrhy, analýzy, přípravu zadání, review, testy, kontroly a orchestraci (preference uživatele pro celý projekt, 2026-09-12).
- **Levnější modely**: samotné kódování delegovat na GPT-5.6 Luna, u složitější implementace na GPT-5.6 Terra nebo Sol. Výsledek kontroluje Astra. Použít všude, kde prostředí umožňuje volbu modelu; změnu modelu běžícího tahu nepředstírat.

## Jak pracovat

- Prostředí: `.venv` vytvořený přes `uv venv --python 3.13 .venv`, závislosti `uv pip install -e .[dev]`.
- Testy: `.venv/bin/pytest -q` (offline, fixtures v `tests/fixtures/<zdroj>/`). Lint: `.venv/bin/ruff check mostek_kultura`.
- Lokální build bez sítě a bez LLM: `python -m mostek_kultura build --offline --no-llm`.
- Nový zdroj existujícího typu = jen záznam v `config.yaml`. Nový typ = modul v `mostek_kultura/sources/` + registrace v `sources/__init__.py` + fixture (`build --record --source <name> --no-llm`) + test.
- Fixtures se nahrávají příkazem `build --record` (zapíše `tests/fixtures/<zdroj>/manifest.json` + soubory). Po změně URL v configu nahrát znovu.
- `cache/last_good/` zapisuje jen CI (env `CI`) nebo `build --persist`; lokální živé buildy ho nemění, aby nevznikaly konflikty s commity z CI. Když konflikt přesto vznikne, vezmi novější verzi souboru.
- LLM klasifikace: `OPENAI_API_KEY` (model `OPENAI_MODEL`, výchozí `gpt-5-mini`) nebo `ANTHROPIC_API_KEY` (`claude-haiku-4-5`); `LLM_PROVIDER` vynutí volbu. Bez klíče jen klíčová slova.
- `cache/` je commitovaná (klasifikace z LLM + poslední dobrý fetch per zdroj). CI ji commituje zpět s `[skip ci]`. Ruční oprava kategorie: editovat `cache/classifications.json`.
- Akce z Facebooku (nedají se stahovat) se doplňují ručně do `manual_events.yaml` (zdroj `rucne`, typ `manual`); formát viz komentář v souboru.
- Testy i offline build jsou na "dnešek" citlivé jen zdánlivě: `dates.now()/today()` respektují env `MOSTEK_NOW` (ISO datum/datetime), testy si ho v `conftest.py` sami nastaví na den nahrání fixtures. Ruční reprodukce toho dne: `MOSTEK_NOW=2026-09-11 python -m mostek_kultura build --offline --no-llm`. `FixtureHttp` navíc při přesném netrefení URL v manifestu zkusí normalizovaný dotaz (stejná cesta a množina klíčů, ignoruje se `rok=`/`mesic=`/`datum_od=`/`datum_do=`/`page=` a hodnoty vypadající jako datum/číslo) – proto zdroje stavějící URL z dnešního data (`public4u`, `vismo`) fungují offline i jiný den.
